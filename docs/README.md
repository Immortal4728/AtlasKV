# AtlasKV Documentation

This directory contains all project documentation.

## Structure

```
docs/
├── adr/            # Architecture Decision Records
├── architecture/   # System design documents
└── diagrams/       # Visual diagrams and figures
```

## Architecture Decision Records (ADRs)

ADRs document significant architectural decisions made during the project. Each ADR is numbered sequentially and follows a consistent template.

See [docs/adr/](adr/) for all records.

## Architecture Documents

System-level design documentation including the four-layer architecture, interface contracts, and module boundaries.

See [docs/architecture/](architecture/) for all documents.
